# 量化管理人综合能力评估 — 指标口径与阈值

本文档定义 `scripts/` 的计算口径、阈值与数据来源，供 SKILL.md 引用。所有计算基于周度净值数据，禁止使用未来函数（只用 `end_date` 之前的数据）。

## 数据窗口与评估区间

- 数据窗口：固定 2 年（104 周），用于计算近 1 年指标及对齐日期。
- 评估区间：数据窗口的最后 1 年（52 周），用于最终评分。
- 日期对齐：若用户指定 date，则以该日之前的最近周五为终点；否则以 API 返回的最新可用周五为终点。
- 净值频率：私募净值以周频为主，统一按 API 返回的周度序列处理。
- 周收益率：`r_t = nav_t / nav_{t-1} - 1`。
- 年化收益：周频复利 × 52。
- 年化波动率：`std × sqrt(52)`。
- 夏普比率：年化收益 / 年化波动（假设无风险利率为 0）。

## 维度 1：收益进攻评分 — 反映管理人获取收益的能力

| 指标 | 计算 | 纳入产品 |
|---|---|---|
| 近1年年化收益 | 产品近1年净值周收益率的年化复利收益 | 300指增、500指增、1000指增、选股 |

计算方式：
1. 将所有纳入产品的近1年年化收益按策略线分组（300指增/500指增/1000指增/选股各自成池），各组独立做 min-max 线性比例打分（最大值 100 分，最小值 0 分，中间按数值比例线性插值）。
2. 管理人在该维度的得分 = 其旗下各产品得分均值。

## 维度 2：收益质量评分 — 反映管理人创造 Alpha 的能力

| 指标 | 计算 | 纳入产品 |
|---|---|---|
| 近1年信息比率（超额夏普比率） | 指增产品近1年周超额收益序列的夏普比率：超额周收益均值×52 ÷ 超额周收益波动×√52（无风险利率为 0） | 300指增、500指增、1000指增 |
| 近1年夏普比率 | 对冲产品近1年周收益率的夏普比率 | 对冲 |

计算方式：
1. 将所有纳入产品的信息比率 / 夏普比率按策略线分组（300指增/500指增/1000指增的信息比率各自成池、对冲的夏普单独成池），各组独立做 min-max 线性比例打分（最大值 100 分，最小值 0 分，中间按数值比例线性插值）。
2. 管理人在该维度的得分 = 其旗下各产品得分均值。

## 维度 3：风格偏离评分 — 反映管理人与基准/风格的偏离程度

> 口径说明：goodluckdata.com 的指数接口返回的是**周一收盘点位**，产品净值是**周五净值**，两者存在 4 天相位错位，周度收益率序列相关性会被系统性压低（指增产品实测仅 0.5~0.6，不符合业务事实）。故本维度相关性采用**累计收益口径**：产品净值序列 vs 归一化指数点位序列的皮尔逊相关系数（实测 0.93~0.96，符合指增紧密跟踪基准的业务直觉）。

| 指标 | 计算 | 纳入产品 |
|---|---|---|
| 与基准指数相关性 | 产品近1年净值序列与归一化基准指数点位序列（均以区间首值为 1）的皮尔逊相关系数 | 300指增、500指增、1000指增 |
| 与万得小市值相关性 | 产品近1年净值序列与归一化万得小市值指数点位序列的皮尔逊相关系数 | 300指增、500指增、1000指增 |

计算方式：
1. 基准相关性正项：相关性越高，说明跟踪基准越紧、风格偏离越小，得分越高。按策略线分组（300/500/1000指增各自成池）做 min-max 线性比例打分（最大值 100 分，最小值 0 分，中间按数值比例线性插值）。
2. 小市值相关性扣分项：相关性越高，说明小市值暴露越大、风格偏离越大，得分越低。按策略线分组做 min-max 反向映射（相关性最高 0 分，最低 100 分）。
3. 管理人在该维度的得分 = `0.7 × 基准相关性分 + 0.3 × (100 - 小市值相关性分)`，再在其产品间取均值。

## 产品覆盖奖励系数

产品覆盖越多，奖励系数越高，表示管理人信息披露越完整、越透明：

| 产品数 | 奖励系数 |
|---|---|
| 5 个 | 1.10 |
| 4 个 | 1.06 |
| 3 个 | 1.03 |
| 2 个 | 1.00 |

产品指 300指增、500指增、1000指增、选股、对冲五条策略线中的产品。不足 2 个产品的管理人不参与评分。

## 综合评分

- 综合分 = `（收益进攻评分 + 收益质量评分 + 风格偏离评分）/ 3 × 奖励系数`，四舍五入到 0.1。
- 管理人按综合分降序排名。

## 管理人筛选规则

- 仅保留旗下至少 2 个产品的管理人参与评分。
- 用户指定管理人列表时，系统仍拉取全市场数据用于全局分位数排名，最终仅显示指定管理人。

## 数据来源

> 数据统一来自 goodluckdata.com 的 HTTP 接口（`config.json` 中 `base_url`，默认 `https://goodluckdata.com`），不读取本地数据库或本地文件。默认凭证 admin/xu753951，可通过 `config.json` 或环境变量 `ALPHA_USERNAME/ALPHA_PASSWORD` 覆盖。

| 数据 | 来源 |
|---|---|
| 产品净值/累计收益序列 | goodluckdata.com `/manager/get_leaderboard_data/`（HTTP） |
| 宽基指数收盘价 | goodluckdata.com `/api/index_dashboard_data/`（沪深300、中证500、中证1000、中证2000、中证全指） |
| 产品×指数相关性（含万得小市值指数） | goodluckdata.com `/api/longterm/correlation/`（fund-index 模式，indexNames 含「万得小市值指数」，窗口近1年） |

## 合规约束

- 本评估只衡量「管理人在特定区间内的相对表现」，不预测未来收益，不给出买卖建议。
- 输出必须带「风险提示」；禁止「保本/稳赚/无风险」等承诺性表述。
- 敏感数据脱敏：仅输出管理人名称与计算指标，不输出 `fund_code / fund_name / 原始净值明细`。
